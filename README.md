# Gaurav Kumar · Portfolio

Personal portfolio site for Gaurav Kumar, B.Tech CSE (2023 to 2027) at SDGI Global University, focused on Java and Android development.

Built with React, Vite, Tailwind CSS, Three.js and Framer Motion. All text, links and lists live in `src/data/portfolio.js`.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build into dist/
```

## Structure

```
src/
  components/    page sections (Hero, About, Skills, Projects, Beyond, Contact ...)
  components/ui/ small shared pieces (Reveal, TiltCard, Icon ...)
  data/          portfolio content
  index.css      theme tokens and font faces
public/          images, fonts, favicon
```
